# 🏫 Student Database Management System

### 📝 Project Description
A clean and structured Python CLI application to handle student academic records. It acts as a lightweight management system that automatically calculates student totals and percentages, saving the persistent records inside a formatted JSON database file.

### 🚀 Key Features
* **📁 JSON File Persistence:** Reads and writes live data directly into a `students_data.json` database.
* **📈 Automated Calculations:** Dynamically processes marks to auto-generate the `Total` score and `Percentage` for every student upon creation or update.
* **⚡ Complete CRUD Operations:** Create, Read, Update, and Delete student records with runtime verification steps.
* **🔄 Deep Dictionary Traversal:** Uses custom recursive iterations to display multi-layered nested student maps.
* **🔒 Robust Input Validation:** Prevents software crashes by filtering non-integer entries using safe exception catching blocks.
